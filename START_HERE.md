# CycloneLens AI — start here

1. **Run locally (no Docker):** see "Local development" in [README.md](README.md). Windows users can double-click `start_windows.bat`.
2. **Deploy:** see "Docker deployment" in [README.md](README.md).
3. **Load data:** create an admin with `python -m app.cli create-admin --email you@example.org`, sign in, and import the IBTrACS CSV on the *Data ingestion* page. The app ships with no data.

This is a research and historical-data exploration platform. It is **not** an operational forecast or warning system.
